# Geometry-Dash-Bundle-of-Lists
A simple webpage showing the most popular and less known fan made GD level lists, handy no matter what your skill level is.

## How to use 
The only thing you need is a web browser. Download the file, and simply click on it to open it. Opening it on a compiler and running it also works, but is not advised unless you want to check out and/or modify the code itself.

### Built entirely with HTML in Visual Studio Code. Future updates might include: making the webpage look more clean with CSS, adding new lists (for suggestions, email me at eggdude131@gmail.com). If any of the creators wants a list to be taken down, email me. Current version: 1.0.0.
